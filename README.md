QuickCart POS is a smart inventory and billing system designed for small businesses.
It helps shop owners manage products, track sales, and generate invoices easily.
#Features: 
    -Product inventory management
    -real-time stock tracking
    -low stock alerts
    -sales and revenue dashboards
    -billing system, invoice generation (PDF). 
    
  #TechStack:
    Python (Flask)
    HTML, CSS 
    SQLite database
    render (cloud deployment)
    
  #LiveDemo:
    https://quickcart-pos.onrender.com/
    
  #HowItWorks: 
     1.Admin logs into the system.
     2.Products are added to the inventory. 
     3.Items are sold through the dashboard.
     4.Stock updates automatically.
     5.Revenue and transaction are tracked.
